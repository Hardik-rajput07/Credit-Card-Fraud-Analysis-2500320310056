**Project Synopsis**



**Problem:**

Credit card fraud does not happen often, but when it does, it costs a lot of

money. It is also hard to find because the fraud transactions are hidden among

thousands of normal ones. In this project, I will study a credit card

transaction dataset to understand how fraud looks and to see if some simple

rules can catch it.



**Objectives:**

1\. Clean the data and write down every problem I fix.

2\. Make at least 3 simple fraud rules (high amount, odd hours, many

&#x20;  transactions in a short time).

3\. Check how good the rules are using precision and recall.

4\. Build a Power BI dashboard that shows the flagged transactions.



**Scope:**

What I will do:

\- Use a public credit card fraud dataset (a smaller sample if it is too big)

\- Clean the data, build the fraud rules, write SQL queries, make a dashboard

&#x20; and write test cases



**What I will not do:**

\- Build machine learning models

\- Detect fraud in real time

\- Use any real customer's data



**Data Source:**

A public credit card fraud dataset from Kaggle. I will write the exact source,

licence and column details in docs/dataset.md.



**Tools:**

Python (pandas), SQL, Power BI, Git and GitHub.



**Deliverables:**

Problem statement, synopsis, SRS, data dictionary, cleaning script, SQL

scripts, Power BI dashboard, test cases, data-quality report, insights summary,

README, GitHub repository and a demo video.



**6-Week Plan:**

\- Week 1: Write the problem statement, synopsis and SRS, and set up GitHub

\- Week 2: Get the dataset, write the data dictionary and clean the data

\- Week 3: Build the fraud rules in Python and write test cases

\- Week 4: Write the SQL schema, queries and views

\- Week 5: Build the Power BI dashboard

\- Week 6: Write the reports and README, record the demo video and do a final

&#x20; check



**Expected Outcome:**

At the end, I will have a clean dataset, at least 3 working fraud rules with

their precision and recall, a dashboard that shows the flagged transactions,

and a complete GitHub repository.
